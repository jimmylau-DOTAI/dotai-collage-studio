# Security

This pre-release editor has no backend and does not upload selected images. Files are decoded locally; keep your browser current and only open images you trust.

Report vulnerabilities privately to the repository owner through your existing private collaboration channel. Do not attach personal photos, tokens, or exploit details to public issues. No security response SLA is promised during private development.

The privacy check is a targeted project safeguard, not a comprehensive secret scanner. Generated HTML and test images must remain untracked. Review the complete Git history again before changing repository visibility.
