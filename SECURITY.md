# Security

This editor has no backend and does not upload selected images. Files are decoded locally; keep your browser current and only open images you trust.

Report vulnerabilities privately to the repository owner through the contact route in the GitHub profile. Do not attach personal photos, tokens, or exploit details to public issues. No security response SLA is promised.

The privacy check is a targeted project safeguard, not a comprehensive secret scanner. Generated HTML and test images must remain untracked. Review the complete Git history again before changing repository visibility.
