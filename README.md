# DotAI Collage Studio

本機運行嘅 1–9 相拼圖工具：一次揀相、自動配合張數排版、框內裁切，再下載 JPG。作品相片只會喺你部機嘅瀏覽器處理。

**公開開源版本 · MIT license · 無後端／無上傳／無追蹤。** 呢個係可下載使用嘅工具，唔係已部署網站。

> **Made by [Jimmy Lau](https://github.com/jimmylau-DOTAI) at DotAI.** 我想將日常社交內容製作入面最磨人嘅「揀相、裁切、排版」變成一個可直接試用、可持續改進嘅本機工具。如果你試用後有想法，歡迎開 Issue（PS：GitHub 入面記錄問題或建議嘅地方）或者 Pull Request（PS：提交一組程式改動畀社群審閱）。

## 開始使用

需要 Node.js **22.22.2+（22.x）、24.15.0+（24.x）或 26+**、npm 及 Git（跟 jsdom 測試依賴嘅支援範圍）。

```sh
npm ci --ignore-scripts
npm run check
```

然後用 Chrome／Safari 開啟 `dist/index.html`。建置後係一個獨立 HTML，唔需要 server，亦唔需要網絡。

1. 開啟時係空白，按「加入相片」選 1–9 張。示範圖只會在按「試玩示範圖」後出現；之後第一次加入真相片會取代全部示範圖。每張最多 40 MB，每次選取最多 120 MB。
2. 揀排版，設定背景色及 1:1／4:5 比例；四張有 26 款不重疊排版，五張有 17 款。
3. 點相片後，用畫布旁 ＋／− 或滾輪縮放，拖圖片揀人物位置；斜切後一樣可用。雙擊只選取，不會開檔案視窗；換圖請用獨立上載按鈕。Command Z／Ctrl Z 復原，加 Shift 重做；文字欄位保留原本的文字復原功能。
4. 做錯按「復原」，完成按「下載 JPG」。

畫布上方固定「相片／相框／斜切」三個獨立模式。點图片內部切入相片模式：藍点縮放、拖中間移焦點；點邊線或留白切入相框模式：橙色圓點改比例。按「斜切」後拖菱形端點改共用分界角度，按「還原直線」取消傾斜。切換模式本身不改作品，拖緊角點時鎖定模式。

相片模式可按「交換」，再點另一張畫布相片或縮圖，毋須記住拖拉手勢；按「取消交換」或 Esc 可取消。原位長按約半秒再拖、拖縮圖及 Shift 拖圖亦保留。畫布旁會按目前操作顯示一句提示，完整手勢及快捷鍵收喺「？」說明；少於兩張時，斜切及交換不可用。

示範圖係程式生成，**唔包含真人活動相**，亦唔會自動混入你嘅作品。程式只在本機讀取你選擇嘅相；沒有 upload endpoint、analytics 或外部字體。

## 現有功能

- 1–9 張自動排版；單張全圖，其餘按張數提供 14–26 款平均分格、橫直排、上／下／左／右主相組合。刻意重疊的畫中畫款式不再在介面出現。
- 1:1：1080×1080；4:5：1080×1350。畫布旁縮放及滾輪直接放大框內圖片，不拉闊原相；普通拖圖片只改构圖，白色圓點先會改排版比例。
- 共用分界調整會同步修改鄰框，不係將相框蓋住其他相片；設最細尺寸以保護留白及標誌空間。自訂比例可再斜切。
- 拖放交換相片會帶埋圖片的縮放及裁切，但保留相框比例；新增／移除相片後重新排版。
- 白色預設，另有十二款通用冷暖及中性色、自選底色；最多保存八隻命名色卡。每張色卡佔完整一行，改名及移除收喺「⋯」。作品唔會預先套用 DotAI 品牌色。
- 白色工作面板、灰藍畫布背景、藍色操作提示與官方方形工具標誌；作品標誌由用戶自行加入，工具身份同作品品牌分開。
- 一次加入多款標誌，最多八款，每張作品選用一款；保留原比例及原色，可標記適合深底／淺底。四角貼邊、頂／底色帶、直接疊圖或小底牌；底板跟作品底色或獨立選色。忽略透明留白只改顯示範圍，唔改原檔。
- 點畫布標誌可直接拖角點調大細，亦可用畫布旁 ＋／−；不會移動下面張相。側欄「刪除標誌」及大小滑桿不用展開進階設定；刪除、拖角點都可以復原。改動不會自動覆蓋已儲存品牌，需要按「儲存我的品牌」保留最新版本。
- 「儲存我的品牌」明確保存標誌、擺位及作品底色到本機瀏覽器，下次開啟自動載入；已命名色卡另行保存。可刪除已儲存品牌，唔會刪走目前作品。沒有雲端／知識庫連接。
- 最近 60 個狀態可復原／重做，整組換相只需一步復原。JPEG 不含編輯選框及控制點，會包含自行加入的作品標誌。

## 已知限制

- 未有相片專案保存／載入，刷新或關閉前要先下載；下載 JPG 不能重新載入成可編輯專案。「儲存品牌」只保存標誌等設定，唔包括活動相片及構圖。
- 每個標誌最多 10 MB，每批最多 40 MB；大尺寸標誌會按比例縮細副本，轉成 PNG，最長邊最多 1024px，透明背景及原檔保留。讀取原圖仍需要裝置記憶體，極大圖片在低記憶體手機可能讀取失敗。品牌儲存有容量上限，超出或瀏覽器拒絕儲存會報錯，唔覆蓋舊紀錄。清除瀏覽器資料或換開檔位置可能令本機紀錄無法再讀取，請保留標誌原檔。
- 「貼邊」直接疊圖時按標誌範圍計；小底牌按底牌外緣計，內側保留留白。頂／底色帶本身全闊，邊距調整其中標誌上下留白。透明留白可略過，實色白底不會自動去除。
- 加／減相片會重新排版並清除自訂比例，保留留下相片的縮放及構圖；換排版亦保留圖片。重新選取整組會重設圖片構圖，但保留底色、畫布比例及標誌。以上都可復原。
- 無兩指縮放承諾：現時直接縮放用滾輪／觸控板滾動或 ＋／−；手機拖放及手勢仍需真人驗收。
- 超過九張不會靜默刪走相片，會提示重新選取；任何一張失敗則整組不變。新一輪換相會取代仍在載入的舊選擇。
- 未提供 Facebook／Instagram 發布、API、排程或廣告功能。
- 自動測試使用 jsdom + native Canvas，**不等同 Chrome／Safari／手機實測**。跨瀏覽器、觸控及下載提示需按下方 checklist 驗收。

## 開發方式

```sh
npm run build          # 輸出 dist/index.html
npm test               # 先有 build，再執行所有測試
npm run check:privacy  # 私人路徑／憑證 pattern 及 staged 檔案檢查
npm run check          # build + test + privacy
```

```text
src/       Canvas 幾何、互動邏輯、HTML 模板及介面 CSS
assets/    限定官方標誌及來源記錄（與日後程式碼授權分開）
scripts/   可重現建置、測試 runner、資料檢查
tests/     幾何、互動、像素及 JPEG 輸出驗證
docs/      規格、來源、路線圖及實作計劃
dist/      生成嘅單檔工具（不入 Git）
artifacts/ 測試預覽（不入 Git）
```

測試涵蓋真實圖片讀取與縮圖、加減相片／多張上載競態、框內移圖像素、斜切覆蓋與分界像素、兩種 JPEG 尺寸、Logo、色板、復原／重做及編輯線排除。生成示範圖不依賴系統字體；同一 runtime 上建置會比對一致性。
