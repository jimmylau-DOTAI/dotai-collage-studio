# 社交圖片拼圖工具：操作簡化與作品標誌

日期：2026-09-19。產品負責人：Jimmy Lau。開發及驗證：Codex。

狀態：Jimmy 已確認產品方向，並於 2026-09-19 以「ok」確認本文件；進入實作計劃階段。尚未實作。

## 1. 目標及本輪範圍

將現有四相拼圖工具收斂成社交圖片製作工具：加入相片 → 揀排版 → 直接拖動 → 選品牌排版 → 下載。

本輪只做三件事：取消操作模式選單、改為正方形與直向尺寸、加入可上載的作品標誌及三款固定位置。

保留既有深海藍工具介面、官方方形 DotAI 標誌、四張相片、29 款排版、底色與間距、復原／重做，以及離線處理。工具本身的標誌不會自動變成作品標誌。

不做：保存作品、記住品牌設定、收藏排版、帳戶、雲端儲存、自動發布、文字編輯、任意繪圖。以上前三項留待下一輪。

本文件取代舊規格中「4:3 橫向、四種操作模式、任意形狀、作品完全不可放標誌」的要求。舊文件保留作歷史記錄。

## 2. 單一直接操作方式

使用者不用切換模式；所點位置決定動作。

| 點擊或拖動位置 | 結果 |
| --- | --- |
| 相片內部 | 選中相片並調整照片在框內的構圖，不移動相框 |
| 選中相框的移動手柄 | 移動整個相框，照片跟隨 |
| 選中相框右下角 | 改相框寬高，照片維持原比例裁切、不拉伸 |
| 相連四格的分界手柄 | 調整四格的共用分界，包括斜切 |

- 所選相片才顯示移動、大小控制；手柄旁有短提示。輸出不含控制線或提示。
- 命中順序固定：已顯示的相框控制 → 已顯示的共用分界控制 → 相片內部。重疊時不隨意猜測，控制項佈局亦須避免互相覆蓋。
- 一次拖動只產生一個復原步驟。拖出畫布仍可完成操作；忽略第二隻手指，不讓拖動跳位。
- 鍵盤可以選相片、微調構圖，亦可以聚焦移動／大小／分界手柄後以方向鍵調整；手柄提供名稱及當前數值。不能只靠滑鼠操作。
- 四格與可調斜切四格提供共用分界；其他既有版式保留單張移位、大小與構圖，不承諾所有異形組合都有共用分界。
- 四格起始分界為直線；拖端點即可斜切，不另外選模式。
- 自由移動或改大單張相框後，該組合不再是假定相連的四格：隱藏共用分界，保留自由相框。要重新連結可重新套用版式，並清楚提示會重設相框；可以復原。不能在使用者不知情下重設自由相框。

移除使用者介面中的四種模式選單、圓／三角形／菱形／六邊形按鈕、自訂頂點及相框座標數字面板。斜切只保留在可理解的共用分界操作中。移除失去入口的事件綁定；無關的程式整理不混入本輪。

## 3. 尺寸與介面

- 1:1 正方形：1080 × 1080。
- 3:4 直向：1080 × 1440，即高四、闊三。
- 移除 4:3 橫向選項，亦不新增 4:5。
- 切換尺寸會按可用相片區域比例換算相框位置及大小，保留相片順序與構圖參數；不把相片拉伸。此操作可復原。

畫布是主角。頂部保留加入相片、尺寸、下載；底部以縮圖選排版。作品底色、間距及品牌排版放在精簡的可收合區塊。選中相片先顯示替換、縮放、置中小工具列，不再常駐一長排技術設定。

窄屏以畫布優先、控制區順序排列，文字與按鈕不超出螢幕。一般按鈕及拖動目標至少 44 個螢幕像素；分界與角位遇上狹窄相框時，需要清楚分離可按區域，不只放大重疊的透明區。

## 4. 上載作品標誌

提供兩個獨立上載位：正方形標誌、長方形全名標誌。第一版接受 PNG、JPG、WebP，每個檔案最多 10 MB，解碼尺寸上限為 4096 × 4096；PNG 透明背景最適合。暫不支援 SVG，以免加入額外檔案處理範圍。

- 使用者手動選擇檔案後只在本機解碼，不傳送到網絡，不把內容加入程式倉庫。
- 以實際可解碼圖片及尺寸驗證，不只信任副檔名。檔案錯誤、過大或解碼失敗時顯示明確提示，保留上一次成功的標誌。
- 不拉伸、不裁走、不自動改色；使用整張圖片等比例放入指定區域。第一版不自動去背或修剪檔案本身的透明邊距。
- 可以替換或移除任何一款標誌；未上載對應圖片時，該排版不可啟用，旁邊直接提供上載入口。
- 作品預設不放標誌；兩款可以同時儲存在當前編輯工作中，但每張作品只顯示所選款式。

## 5. 三款品牌排版

| 選項 | 使用檔案 | 行為 |
| --- | --- | --- |
| 不放標誌 | 無 | 不預留標誌區域 |
| 左上角 | 正方形 | 在作品左上安全邊距內覆蓋顯示，不預留橫條 |
| 中上 | 長方形全名 | 頂部預留白色品牌橫條，照片排在橫條以下 |
| 中下 | 長方形全名 | 底部預留白色品牌橫條，照片排在橫條以上 |

這些是品牌排版選擇，不是另一套操作模式。

- 標誌區只提供「大小」和「邊距」。左上角款預設佔作品寬度 12%，可調 6–24%；邊距預設 24、可調 12–64 個輸出像素。
- 全名款預設佔作品寬度 24%，可調 12–40%；同樣的邊距適用於白條上下留白。
- 頂部／底部橫條按等比例標誌高度加上下留白計算，最多佔畫布高度 20%；超出時等比例縮小標誌，不能裁走標誌或把相片壓至不可用。
- 左上角款是覆蓋在照片上的固定位置，不保證避開人物；即時預覽顯示真實效果，提示「避免遮住重要內容」。不要聲稱有自動人像避讓。
- 更換標誌大小、位置、圖片或尺寸時，共用同一套相片可用區域計算，普通排版、斜切、自由相框都必須遵守；已有相框按區域換算，不突然消失或落入品牌橫條。
- 預覽與下載使用同一份作品繪製資料，確保標誌位置、大小、透明度與白條一致。工具介面標誌永不混入作品。
- 切換款式、上載、替換、移除及調整大小／邊距均可復原。移除正在使用的標誌會切回不放標誌，可復原；缺少檔案時不能靜默輸出另一款。

## 6. 程式分工與資料

- 幾何與繪製層：統一尺寸、相片可用區域、相框、分界、標誌區域及輸出；純計算可獨立測試。
- 互動層：選取、控制項命中、拖動、鍵盤微調及歷史紀錄；不依賴已移除的模式選單。
- 素材層：管理相片與兩款標誌的已解碼圖片。編輯狀態只保留素材識別，不在每一步歷史紀錄複製完整圖片。
- 樣式與頁面層：畫布優先的簡潔控制區，保留深海藍工具外觀。
- 同一張被替換的素材，只要仍由現況或復原／重做紀錄引用就保留；不再引用時釋放，避免新標誌上載放大既有重複上載記憶體問題。
- 不新增網絡請求或執行套件。完成後仍輸出單一可離線打開的網頁檔案。

## 7. 驗收標準

1. 使用者不用揀操作模式，便可拖相片、移框、改大小及拉四格斜切；任意形狀控制已移除。
2. 兩個下載尺寸精確為 1080×1080、1080×1440；舊橫向選項不存在。
3. 三款標誌排版加「不放標誌」均在兩種尺寸、普通／斜切／自由相框下正確運作。
4. 全名標誌不變形，白條不被照片蓋住；方形標誌位置與預覽一致。
5. 上載失敗保留舊標誌，缺少標誌不容許誤選；所有品牌編輯均可復原及重做。
6. 拖出畫布、取消拖動、鍵盤及多指情況有明確結果；編輯控制不出現在下載圖。
7. 換標誌、換尺寸、換品牌位置，不丟失照片順序；可用區域內的相框和斜切對齊。
8. 自動測試覆蓋上述狀態及圖片像素；真人另驗收 Chrome、窄屏、觸控、檔案選擇及下載。自動測試通過不等於真人驗收完成。
9. 不上傳任何使用者照片或標誌；沒有新增遠端字體、圖片或資料傳送。
